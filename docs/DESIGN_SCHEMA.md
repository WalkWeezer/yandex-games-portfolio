# Схема диздоков портфеля (обязательная)

Каждая игра в `games/<slug>/` содержит:

| Файл | Назначение | Для кого |
|------|------------|----------|
| `docs/DESIGN.md` | Классический GDD | человек / продюсер |
| `docs/DESIGN_LLM.md` | Исполняемая спецификация | LLM-агенты |
| `prompts/*.md` | Атомарные промпты (вырезки из DESIGN_LLM) | отдельные агенты |
| `refs/art|ui|levels|sprites/` | Визуальные референсы | арт/код агенты |

**Правило:** разработка кода (`src/`) не начинается, пока в `management/portfolio-dashboard.html` статус дизайна игры = `CONFIRMED`.

## Статусы дизайна

`DRAFT` → `REVIEW` → `CONFIRMED` → (можно Gate 0 разработки)
