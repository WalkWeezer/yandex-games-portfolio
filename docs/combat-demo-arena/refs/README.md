# Combat Demo Arena — Reference Images

**Канон чисел и биндов:** только [`../COMBAT_MECHANICS.md`](../COMBAT_MECHANICS.md).  
Эти PNG — blocking-референсы настроения/силуэтов. Если арт спорит с каноном — **побеждает канон**.

Известные расхождения арта (игнорировать при имплементации):
- На HUD-мокапе Debt может быть нарисован как большое число → в демо Debt **0–50**.
- В lineup оружия могут быть bow/hammer → в v0 демо только **Cleaver, Spear, Twin Knives, Orb, Grimoire, Staff**.
- EN-лейбл L1/L2 на контроллере может дублировать «Skill A» → канон: L1=Skill1, L2=Skill2.

Art direction: cold stone crypt / wet iron / ash + ember; muted teal-slate. Isometric readability. Avoid purple-on-white, cream+terracotta, broadsheet.
