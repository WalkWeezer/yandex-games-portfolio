# Демо-арена: боевые механики (канон)

**Статус:** утверждённый дизайн-канон для демо-арены.  
**Жанр:** изометрический hardcore action (вес soulslike + маршруты immersive sim).  
**Ограничения демо:** без левелинга персонажа; без роглайк-обёртки; бой самодостаточен.  
**Ввод:** DualSense-first.

Документ снимает все развилки однозначно. Если что-то не описано здесь — это вне скоупа демо.

---

## Решения по проблемам (порядок фиксирован)

| # | Проблема | Решение (канон) |
|---|----------|-----------------|
| 1 | Когнитивная перегрузка | **Враг важнее алхимии.** Телеграфы врага всегда поверх. Среда читается вторым слоем и только по запросу (прицел скилла / удержание L2). |
| 2 | Сила магических шасси vs клинки | **Разные роли, не равный DPS.** Клинок: выше poise/stagger и надёжный ближний урон. Магия: дальность, AoE, феномены; прямой урон Attack A/B −25% vs клинок того же тира. |
| 3 | Пресет vs импровизация скиллов | **Пресет слотов, импровизация комбинации.** Skill 1/2 выбираются до боя и не меняются в бою. Комбинация Skill1+Skill2 — live, в бою. |
| 4 | Иерархия рун / скиллов / среды | **Скилл = акт силы. Руна = пассив оружия. Среда = носитель/усилитель.** Spark-руна ≠ Spark-скилл. |
| 5 | Броня не выигрывает в меню | Макс. 2 руны брони, у каждой обязательный штраф, конфликт одной Силы, без стака одинаковых эффектов. |
| 6 | Цена магии | **Focus + Debt + Backfire** одновременно (правила в §B и §H). |
| 7 | Среда обязательна для сильных эффектов | **Явления Tier-2 требуют носителя.** Tier-0/1 работают без среды. |
| 8 | Смена оружия в бою | 1 запасное оружие; свап 0,6 с commitment; CD 4,0 с; меняет только Attack A/B и руны оружия. |
| 9 | DualSense | Полная карта в §C; combine = одновременное удержание R1+R2 ≥ 120 мс. |
| 10 | Референс-бой | Одна комната, 2 адда + босс; три валидных клира: melee / magic / hybrid (§I). |

## A. Combat pillars

1. **Читаемость врага первична.** Игрок сначала читает телеграф и позицию, потом решает «бить / кастовать / использовать среду». Никакой алхимический эффект не перекрывает силуэт и индикатор атаки врага.
2. **Вес и commitment.** Атаки, касты, свап и уклонение имеют окна отмены и восстановления. Спам проигрывает таймингу.
3. **Мастерство без уровней.** Сила растёт через знание телеграфов, носителей, сочетаний сил и управление Focus/Debt — не через статы персонажа.
4. **Три равноправных победы.** Чистый melee, чистая магия и hybrid должны закрывать демо-арену без «обязательного» билда.
5. **Две активные силы, один феномен.** Loadout несёт ровно Skill 1 и Skill 2; их совместное удержание создаёт явление. Больше двух активных сил в демо нет.
6. **Среда — маршрут силы, не декор.** Носители (лужа, факел, труп, тень) нужны для Tier-2 явлений и части гибридных клиров.
7. **Руны правят оружием, не заменяют скиллы.** Руна меняет поведение Attack A/B и пассивы; она никогда не является «бесплатным кастом» той же Силы.

## B. Resources (точные правила демо)

### B1. Hit Points (HP)
- Максимум: **100**.
- Смерть при HP ≤ 0. Рестарт арены с тем же loadout.
- Лечения в демо-арене **нет** (никаких флаконов). Единственный источник восстановления HP — **не используется** в демо (осознанно). Игрок проходит на ресурсе входа.
- Урон отображается числами; критический удар = ×1,5 и отдельный SFX/haptic.

### B2. Stamina (STA)
- Максимум: **100**.
- Траты:
  - Лёгкая атака (Attack A): **12**
  - Тяжёлая / особая (Attack B): **22**
  - Уклонение (dodge): **28**
  - Блок-поглощение удара (если шасси умеет блок): **8 + 0,35 × входящий poise-урон**
- Реген: **28 STA/с** после **0,35 с** без траты STA.
- При STA < стоимости действия: действие **не стартует** (исключение — см. Debt для магии, не для STA).

### B3. Focus (магический ресурс)
- Максимум: **100**. Старт боя: **100**.
- Траты:
  - Одиночный скилл (Skill 1 или Skill 2): **24 Focus**
  - Комбинация Skill1+Skill2 (явление Tier-1): **40 Focus**
  - Явление Tier-2 (с носителем): **40 Focus** + расход носителя (см. §E)
- Реген Focus: **10 Focus/с**, начинается после **0,80 с** без каста/комбинации.
- Каст при Focus ≥ стоимости: Focus списывается сразу в начале wind-up.

### B4. Debt (долг Focus)
- Диапазон: **0–50**.
- Если игрок инициирует скилл/комбинацию при Focus < стоимости:
  - Каст **разрешён**.
  - Недостающий Focus превращается в Debt 1:1 (пример: нужно 40, есть 15 → Focus→0, Debt += 25).
  - Если Debt упёрся в 50, остаток недостачи **не кастуется** (каст отменяется в первые 100 мс, Backfire не вызывается).
- Эффекты Debt (пока Debt > 0):
  - Реген STA: **×(1 − 0,01 × Debt)** (при Debt 50 → реген STA ×0,5).
  - Реген Focus: **×(1 − 0,012 × Debt)** (при Debt 50 → реген Focus ×0,4).
  - При Debt ≥ **30**: каждое уклонение дополнительно стоит **+6 STA**.
  - При Debt ≥ **40**: следующий каст/комбинация имеет **обязательный roll Backfire** (см. §H).
- Снижение Debt: **6 Debt/с**, только когда Focus ≥ 60 и игрок **не** в wind-up каста. Иначе Debt не падает.

### B5. Poise (устойчивость) — игрок и враг
- Игрок: Poise max **80**. Stagger при Poise = 0 → 0,70 с уязвимости, Poise восстанавливается до 40 сразу после stagger, далее реген 20/с.
- Урон по Poise наносят атаки с меткой poise (см. §D). Во время dodge i-frames poise-урон = 0.
- Враги: значения в §I.

### B6. Что демо явно не использует
- Mana как отдельный пул (есть только Focus).
- Кулдауны на одиночные скиллы (ограничение — Focus/Debt/анимации).
- Комбо-счётчик ударов как ресурс.

## C. DualSense control map (каждый ввод)

Контекст: бой на арене. Меню паузы — Options. Вне боя те же бинды, кроме свапа (разрешён всегда вне commitment).

| Ввод | Действие | Примечание |
|------|----------|------------|
| **Левый стик** | Движение | 8-way + аналог скорости. Sprint нет. |
| **Правый стик** | Камера / лёгкий стрейф прицела | В демо камера фиксирована изометрически; правый стик = **смещение прицельной точки** скилла в радиусе 3 м от персонажа (soft aim). Deadzone 0,12. |
| **× (Cross)** | Уклонение (dodge) | 0,18 с i-frames с кадра 2; направление = левый стик, иначе назад от угрозы. |
| **○ (Circle)** | Взаимодействие (тап) / блок (hold ≥ 200 мс на `canBlock` шасси) | Приоритет: см. §D1.0. На magic / Twin Knives hold игнорируется как блок. |
| **□ (Square)** | Attack A | Лёгкая атака активного оружия. |
| **△ (Triangle)** | Attack B | Тяжёлая / особая атака активного оружия. |
| **R1** | Skill 1 (удержание = заряд/удержание, тап = каст) | Тап < 200 мс = мгновенный каст одиночного Skill 1. Удержание ≥ 200 мс = charge (если скилл имеет charge; иначе просто удерживает готовность к combine). |
| **R2** | Skill 2 | Аналогично R1. |
| **R1 + R2** одновременно ≥ **120 мс** | **Combine** → явление | Приоритет выше одиночного каста. Если отпустить один раньше 120 мс — считается одиночным скиллом той кнопки, что держалась дольше. |
| **L1** | Смена оружия (модификатор) | Сам по себе ничего. |
| **L1 + △** | Weapon swap | Свап на запасное. Commitment 0,60 с, CD 4,00 с. Во время commitment: нельзя Attack/Skill/Dodge; можно движение ×0,4. |
| **L2** | Режим чтения среды (Environmental Read) | Удержание: подсвечивает носители в радиусе 8 м (контур), приглушает VFX урона. **Не пауза.** Движение разрешено; атаки отменяют L2. |
| **L3** | — | Не используется в демо. |
| **R3** | Lock-on ближайшей угрозы | Переключение: следующий враг в 10 м по углу камеры. Повторный R3 / смерть цели = сброс. |
| **Touchpad клик** | Быстрый статус | Показать Focus/Debt/STA числа 1,2 с. Не пауза. |
| **Create** | — | Не используется. |
| **Options** | Пауза | Полная пауза демо. |
| **D-pad ↑** | Экипировка Skill 1 (только **вне боя** / до старта арены) | В бою ввод игнорируется + короткий haptic deny. |
| **D-pad ↓** | Экипировка Skill 2 (только вне боя) | То же. |
| **D-pad ← / →** | Выбор пресета loadout до старта | В бою игнорируется. |

### C1. Haptic (обязательный минимум демо)
- Попадание Attack A: короткий tick.
- Attack B / stagger врага: тяжёлый pulse.
- Debt ≥ 30: низкочастотный «гул» пока Debt ≥ 30.
- Backfire: резкий двусторонний удар 200 мс.
- Телеграф врага «красный»: направленный pulse со стороны угрозы (если API доступен; иначе общий warning pulse).

### C2. Adaptive triggers (демо)
- **R2**: лёгкое сопротивление при Focus < 24; сильное при Debt ≥ 40.
- **L2**: мягкое сопротивление в Environmental Read (чтобы палец чувствовал режим).

## D. Weapon chassis list (демо) + Attack A/B

### D0. Общие правила оружия
- Оружие = **Chassis + Material + до 2 Weapon Runes**.
- В демо Material влияет только на: бонусный тип урона (физический / одна Сила) и коэффициент прочности stagger (таблица ниже). Глубокий крафт вне скоупа.
- Активно одно оружие; одно в запасе.
- Свап меняет Chassis+Material+Weapon Runes. Skills и Armor Runes **не** меняются.

**Коэффициенты Material (демо):**

| Material | Множитель урона HP | Множитель poise | Сила-тег |
|----------|--------------------|-----------------|----------|
| Iron | 1,00 | 1,00 | — |
| Embersteel | 0,92 | 0,95 | Ash (DoT 2/с × 3 с при крите) |
| Tideglass | 0,90 | 0,85 | Tide |
| Whisperwood | 0,88 | 0,80 | Whisper |
| Rootbone | 0,94 | 1,10 | Root |

### D1. Шасси ближнего боя (Blade family)

#### D1.0 Блок (канон, без конфликта с L1)
- L1 занят свапом → блок **не** на L1.
- Блок = **удержание ○ ≥ 200 мс** на шасси с `canBlock: yes` (Cleaver, Spear).
- Если в радиусе 1,5 м есть интерактив: **тап ○** = взаимодействие; **hold ○ ≥ 200 мс** = блок (взаимодействие не стартует). Если интерактива нет: тап ○ — idle (короткий haptic deny), hold = блок.
- Блок снижает входящий HP-урон melee на **55%**, ranged на **25%**; poise-урон проходит ×0,6. STA за поглощение — по §B2.
- Идеальный блок (начало контакта в первые 0,12 с после появления хитбокса): poise-урон ×0,0, атакующий получает poise 12.
- Twin Knives / все Magic chassis: `canBlock: no`.

#### 1) Cleaver (тесак)
- Роль: надёжный stagger, короткая дистанция.
- Attack A: горизонтальный рубящий, дуга 90°, радиус 1,6 м, урон **18**, poise **22**, startup 0,22 с, active 0,10 с, recovery 0,28 с. Можно отменить dodge с кадра recovery ≥ 50%.
- Attack B: рубящий сверху, радиус 1,8 м, урон **32**, poise **40**, startup 0,42 с, active 0,12 с, recovery 0,48 с. При попадании в staggered врага: +10 урона.
- Блок: да. Правило блока для всех blade-шасси с блоком — см. **D1.0**.

#### 2) Spear (копьё)
- Роль: дистанция melee, poke.
- Attack A: укол, луч 2,4 м × ширина 0,45 м, урон **15**, poise **16**, startup 0,18 с, recovery 0,24 с. Можно шагать во время startup ×0,5 скорости.
- Attack B: выпад-charge (удержание △ до 0,55 с), дистанция 2,8–3,2 м, урон **28–36**, poise **30–38**, recovery 0,40 с. Отмена dodge только в первые 0,15 с charge.
- Блок: да (`canBlock: yes`, §D1.0). Блок во время charge Attack B невозможен.

#### 3) Twin Knives (парные ножи)
- Роль: скорость, мало poise, fine positioning.
- Attack A: двойной удар, урон **10+10**, poise **8+8**, startup 0,12 с, recovery 0,16 с. Серия до 3 А без потери темпа; 4-й удар принудительно чуть длиннее recovery 0,28 с.
- Attack B: крест-разрыв, урон **24**, poise **18**, накладывает **Bleed 6/с × 2 с** (физический), startup 0,30 с, recovery 0,34 с.
- Блок: нет. Вместо блока — авто-микрошаг назад на 0,2 м при идеальном dodge (награда за чтение).

### D2. Магические шасси (Magic family)

**Общий штраф справедливости:** Attack A/B магических шасси наносят **×0,75** к HP-урону относительно «эквивалентного» клинка; poise ×0,70. Компенсация — доступ к lean-in на Skill timing и лучший soft-aim.

#### 4) Orb (орб)
- Роль: короткие снаряды, ритм кастов.
- Attack A: снаряд-искра (не Сила Spark, а физико-магический bolt), скорость 14 м/с, урон **12** (уже с учётом ×0,75 → номинал 16×0,75), poise **8**, startup 0,16 с, recovery 0,20 с. Хитскан нет.
- Attack B: орб зависает 0,80 с перед игроком, затем взрыв радиус 1,4 м, урон **22**, poise **14**. Можно детонировать повторным △. Если не взорвать — автодетонация.
- Особенность: после любого одиночного скилла следующее Attack A в течение 0,50 с получает **+4 урона** (weave window).

#### 5) Grimoire (книга)
- Роль: зоны и метки.
- Attack A: направленная руна-метка на пол в soft-aim точке (дальность ≤ 5 м), через 0,35 с активируется импульс урон **14**, poise **10**, радиус 1,0 м. Одновременно активных меток: **2**.
- Attack B: страница-щит 0,90 с: поглощает **1** вражеский снаряд или снижает ближайший melee-удар на 35% урона. STA cost Attack B стандартный. Не стекируется.
- Особенность: комбинирование скиллов во время активной метки даёт метке тег Силы первого скилла в комбинации (визуал только; механический бонус — +10% радиус метки на 2 с).

#### 6) Staff (посох)
- Роль: тяжёлые импульсы, контроль пространства.
- Attack A: ближний удар древком, радиус 1,7 м, урон **14**, poise **18** (выше, чем у других magic — исключение), startup 0,24 с, recovery 0,30 с.
- Attack B: продольная волна 4 м × 1,2 м, урон **20**, poise **16**, startup 0,48 с, recovery 0,52 с. Отталкивает лёгких врагов на 1,5 м.
- Особенность: стоять неподвижно 0,40 с перед Attack B → волна получает **pierce** (не гасится первым трупом).

## E. Forces + single-skill effects + skill+skill phenomena

### E0. Пять Сил (fantasy, не физика)

| Сила | Суть | Цвет телеграфа игрока |
|------|------|------------------------|
| **Spark** | Разряд, воспламенение, резкий пик | Янтарный |

Startup combine: **0,45 с**, recovery **0,30 с**, стоимость **40 Focus**. Dodge-cancel только в первые 0,12 с.

Если в loadout две одинаковые силы — **запрещено** уже на экране экипировки.

| Spark+Whisper | **Режущая вспышка** | Линия 6 м мгновенно: урон **34**, poise **14**, невидима для врагов 0,2 с после (агро-сброс лёгкий). |

### E4. Почему Spark-руна ≠ Spark-скилл (иерархия)

| Слой | Что делает Spark | Чего не делает |
|------|------------------|----------------|
| Skill Spark | Активный разряд, тратит Focus, имеет телеграф каста | Не модифицирует автоатаки постоянно |

| Armor Rune «Spark Skin» | При получении удара: 8 урона атакующему 1 раз / 2 с | Не даёт кастовать Spark |
| Environment | Факел/масло усиливают Spark-явления до Tier-2 | Сами по себе не бьют без действия игрока |

Приоритет визуального шума (проблема 1): **телеграф врага > силуэт игрока > VFX скилла > подсветка носителя (L2) > рунные idle-частицы**.

## F. Rune system rules (оружие)

### F1. Слоты
- У каждого оружия: **2 слота Weapon Runes**.
- Пустые слоты допустимы.
- Руны ставятся только **вне боя**.

### F2. Конфликты
1. Нельзя две руны с одним и тем же **Rune ID**.
2. Нельзя две руны одной **Force family**, если обе имеют тег `ForceExclusive` (все Force-руны ниже имеют этот тег).
3. Руна с тегом `Stance` конфликтует с другой `Stance`.
4. При конфликте экипировка блокируется в UI; в бою такой стейт недоступен.

### F3. Каталог демо (оружие)

## G. Armor rune rules

### G1. Слоты и жёсткие ограничения (анти-меню)
- Слотов брони: **ровно 2**.
- Каждая руна брони **обязана** иметь штраф ≥ заявленного в таблице (нельзя «чистый бонус»).

## H. Cast / combine timing, telegraphs, backfire

### H1. Таймлайн одиночного скилла
1. Input accepted → wind-up **0,28 с** (телеграф игрока: цвет Силы под ногами + заряд на R1/R2).
2. В T+0,00–0,10 с: dodge-cancel разрешён; Focus/Debt уже зарезервированы, при отмене возвращаются **100%**.
3. После 0,10 с: commitment; попадание врага в игрока может сделать **cast stagger** (если входящий poise ≥ 25) → каст fail, Focus потрачен, Debt не снимается, **Backfire нет**.
4. Active / release эффекта.
5. Recovery **0,22 с**.

### H2. Таймлайн combine
1. R1+R2 удерживаются ≥ 120 мс → вход в combine wind-up **0,45 с**.
2. В T+0,00–0,12 с: dodge-cancel; ресурс возвращается.
3. В T+0,12–0,45 с: проверка носителя на кадре release (конец wind-up).
4. Release: Tier-2 если носитель валиден, иначе Tier-1.
5. Recovery **0,30 с**.

### H3. Телеграфы врага (приоритет чтения)
- **Жёлтый** контур: атака ≤ 0,45 с до active.
- **Красный** контур + haptic: активный хитбокс или unblockable.
- Телеграфы **не** маскируются VFX скиллов игрока (шейдер priority).
- L2 Environmental Read **не** скрывает телеграфы врага.

### H4. Backfire — точные правила
Backfire происходит только если:
- **(A)** каст/combine начат при Debt ≥ 40, **или**
- **(B)** cast stagger прервал combine после commitment (не одиночный скилл).

Эффект Backfire:
- Игрок получает **12 HP** урона (неигнорируемый бронёй отражения).
- Poise игрока −30.
- Короткий self-stagger **0,35 с**.
- Активный каст отменяется; Focus уже потрачен.
- Haptic: см. §C1.

Нет случайного Backfire при Debt < 40 и чистом касте.

### H5. Прерывания и приоритеты ввода
Приоритет от высшего:
1. Уже начатый commitment (атака/каст/swap)
2. Dodge (если cancel-окно открыто)
3. Combine (R1+R2)
4. Skill tap
5. Attack B
6. Attack A
7. Interact/Block
8. Swap request

## J. Acceptance criteria (демо проходит, если)

### J1. Ощущения (обязательный playtest, 3 проходителя × 3 маршрута)
1. **Чтение врага важнее луж.** В слепую запись: игрок называет телеграф босса раньше, чем тип носителя рядом, в ≥ 80% опасных окон.
2. **Клинок не слабее магии в финале.** Медианное время клира M1 и M2 отличается ≤ **20%**.
3. **Combine ощущается решением, не спамом.** Среднее число combine за клир ∈ [3, 10]; Backfire случается хотя бы раз у новичка и избегается у того же игрока на 3-м заходе.
4. **Среда нужна для силы, не для валидности.** M1 проходит без Tier-2; M2/M3 используют Tier-2 осмысленно; попытка M2 без носителей удлиняет бой ≥ 30%.
5. **Броня не ломает меню.** Ни один из двух-рунных сетов не даёт «безопасный автовин»; Glassmind наказывает за Debt ощутимо.
6. **Свап — обязательство.** Игрок не может свапать «в кадре» без риска: попадание в commitment swap = урон/stagger.
7. **DualSense читается без подсказок HUD** после одного туториал-баннера: R1/R2/combine/L2/swap.

### J2. Технические критерии (билд арены)
- [ ] Все ресурсы §B реализованы с числами ±0 допусков (не «примерно»).

- [ ] L2 подсветка носителей не перекрывает красные телеграфы.
- [ ] Свап: 0,60 с commitment, 4,00 с CD, меняет только оружие.

### J3. Вне скоупа демо (не чинить «отсутствием»)

## Приложение: словарь для реализации

| Термин | Значение |
|--------|----------|
| Commitment | Окно, где действие нельзя отменить атакой/кастом; dodge только если явно разрешён |
| Weave window | Короткое окно усиления Attack A после скилла (Orb / Weaver Coil) |
| Carrier / носитель | Объект среды, расходуемый или постоянный, нужный для Tier-2 |
| ForceExclusive | Тег руны: не более одной руны данной Силы на оружии |
| Soft-aim | Точка в радиусе 3 м, смещаемая правым стиком |
| Tier-0/1/2 | Одиночный скилл / combine без носителя / combine с носителем |

**Конец канона.** Любое изменение чисел — только через явную правку этого документа с пометкой версии.
