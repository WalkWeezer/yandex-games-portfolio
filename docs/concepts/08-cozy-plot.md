# 08 — Уютный Участок

**Жанр:** Cozy farm / life-sim lite  
**Сегмент ЦА:** H — cozy, 20–50  
**Приоритет:** P1  
**Платформа:** Яндекс Игры

![Ключевой арт](../../assets/concepts/08-cozy-farm.png)

---

## One-liner

Восстанови маленький участок у реки: сажай, готовь, декорируй и выполняй заказы соседей.

## Fantasy / сеттинг

Тёплая деревня у реки. Без стресса и таймеров « suffocating» — мягкие дедлайны заказов.

## Core loop

1. Посади/собери урожай.  
2. Переработай на кухне/мастерской.  
3. Сдай заказ → монеты/репа.  
4. Купи декор и расширения.  
5. Открой новых NPC и зоны.

## Механики MVP

- Грядки, 8 культур, 2 животных.  
- 15 заказов, 3 NPC.  
- Декор 20 предметов.  
- День/вечер цикл (косметический).

## Монетизация (hybrid + cosmetics)

| Источник | Как |
|----------|-----|
| Rewarded | Ускорить рост, +слот заказа, daily seed |
| Interstitial | При переходе в деревню (редко) |
| IAP | Декор-паки, pass, энергия/удобрения, remove ads |
| Soft | Монеты, репутация |

## Скоуп MVP → Store Ready

- Участок + река + 1 зона расширения, заказы, декор, экономика.

## Риски

- Контент дорогой → модульный декор и сезонные ивенты.

## Критерии готовности к стору

- [ ] 40+ минут осмысленного контента.  
- [ ] Нет жёсткого paywall на расширение первой зоны.
