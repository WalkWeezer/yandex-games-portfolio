# 04 — Живи Футболом

**Жанр:** Online football manager (оболочка SoccerLife × матч/тактика FM-lite)  
**Сегмент ЦА:** D — спорт / менеджеры, 16–45  
**Приоритет:** P1 (флагман LTV)  
**Платформа:** Яндекс Игры (HTML5) + позже Web/Android  

> **Замена слота:** «Легенды Поля» (CCG×autochess) сняты — механика не формулируется.  
> Здесь механика **уже известна**: берём готовые куски и компонуем.

---

## One-liner

Стань менеджером клуба: между матчами веди клуб как в онлайн-менеджере, а в матче принимай тактические решения как в Football Manager — с live-вмешательствами.

## Формула компоновки (канон)

```text
Живи Футболом = A + B + C

A. Оболочка SoccerLife
   клуб · календарь · таблица · трансферы · инфраструктура · VIP/ячейки · комьюнити

B. Ядро матча FM-lite
   формация · роли · командные инструкции · форма/усталость · post-match отчёт (xG-лайт)

C. USP live-control (из SoccerLife)
   2–4 вмешательства за матч: смена прессинга / ширина / замена / «играть на результат»
```

**Не изобретаем жанр.** Склеиваем два понятных продукта.

| Берём | Откуда | Зачем |
|-------|--------|-------|
| Клубный хаб, сезон, финансы-лайт, трансферы | SoccerLife / Top Eleven | daily return, монетизация VIP |
| Роли, инструкции, читаемый матч-отчёт | Football Manager | «умный» матч, глубина без Excel |
| Live-смены тактики в матче | SoccerLife USP | отличие от чистого автосимулятора |
| Сезон 28 дней, battle pass, RV | Top Eleven | удержание и гибрид на Яндекс Играх |

| Не берём | Почему |
|----------|--------|
| CCG / карты / autochess / синергии-стаки | размытая механика («Легенды Поля») |
| Полный FM (зарплаты Excel, 50 экранов, глобальная база) | не влезает в веб-сессию и бюджет |
| Реальные имена/клубы в MVP | лицензии; на старте — вымышленная лига |
| Букмекер / ставки | модерация и риск |

---

## Fantasy / сеттинг

Вымышленная «Континентальная лига» (16–20 клубов на старте). Игроки с вымышленными именами, позициями и атрибутами. Позже можно добавить «национальные» дивизионы без реальных брендов. Эмоция: *мой клуб, моя тактика, моя таблица*.

---

## Два цикла (оба очевидны)

### A. Матч-день (8–15 мин)

1. Состав 11 + скамейка (тап по слотам).  
2. Тактика FM-lite: формация (3 пресета MVP) + до 4 командных инструкций + роль на 3–5 ключевых игроках.  
3. Матч идёт симуляцией с таймлайном событий; игрок делает **до 3 live-решений** за игру.  
4. Итог: счёт, xG-лайт, рейтинги, форма, деньги, очки в таблице.

### B. Межматчевый день (3–7 мин)

1. Тренировка (1 план на день).  
2. Трансферный рынок / аренда (soft + hard).  
3. Инфраструктура: база / стадион / молодёжка (3 здания, уровни).  
4. Календарь: следующий соперник, таблица, кубок.

**Сессия «зашёл на 5 минут»** = посмотреть результат / сменить инструкцию / ткнуть тренировку.  
**Сессия «матч-день»** = полный цикл A.

---

## Механики MVP (жёсткий скоуп)

- 1 лига, 16 клубов, сезон **14 туров дома/гости упрощённо** или **28 календарных дней** с 2–3 матчами/нед.  
- Состав: 18–22 игрока на клуб; атрибуты сжаты до **6** (PAC/SHT/PAS/DEF/PHY/MEN) + позиция + роль.  
- Формации MVP: `4-3-3`, `4-4-2`, `3-5-2`.  
- Инструкции MVP (вкл/выкл или 3 положения): Прессинг, Ширина, Темп, Стиль финиша (держать/атаковать).  
- Live-control: смена инструкции, замена, «автобус/все вперёд» (по 1 за тайм лимит).  
- Матч-движок: **событийная симуляция** (не физика мяча 11v11).  
- Режимы: карьера vs AI-клубы (MVP); PvP-турниры — после стабилизации движка.

## Монетизация (proven-комбо)

| Источник | Как (из SoccerLife / Top Eleven) |
|----------|----------------------------------|
| VIP / Premium | 2-я ячейка клуба, расширенный скаут-отчёт, +оффлайн календарь |
| Convenience | ускорение лечения/тренировки, доп. скаут-слот, undo замены |
| Soft+Hard | клубные деньги + токены на трансферы/бусты |
| Rewarded | бесплатный скаут-отчёт дня, +форма лидеру, x2 daily reward |
| Interstitial | после матча / при смене экрана хаба (лимиты SDK) |
| Pass | сезонный: косметика формы/стадиона + soft + 1 convenience |
| Косметика | формы, гербы, стиль комментария, борды стадиона |

**Анти-токсик:** hard не покупает «+20 к пасу». Hard = время, информация, слоты, косметика. Сила — через состав и тактику.

## Почему это лучше «Легенд Поля»

| | Легенды Поля | Живи Футболом × FM |
|--|--------------|---------------------|
| Жанр | CCG×autochess×менеджмент | один жанр: футбольный менеджер |
| Объяснение новичку | «собери колоду, стекни★…» | «управляй клубом, выиграй матч» |
| Референсы | смесь трёх игр | SoccerLife + FM + Top Eleven |
| Монетизация | гача-карты (спорно) | VIP / время / pass (проверено) |
| Формулировка механики | не сходится | куски уже существуют |

---

## Скоуп MVP → Store Ready

1. Хаб клуба + календарь + таблица.  
2. Состав / 3 формации / 4 инструкции.  
3. Событийный матч + 3 live-действия + отчёт.  
4. Тренировка + трансферы-лайт + 3 здания.  
5. SDK: cloud save, RV, interstitial, VIP, remove ads, pass light.  
6. 1 учебный матч; лидерборд сезона.

## Риски

- Матч-движок «не чувствуется» → итерации на feel отчёта и live-control, не на физике.  
- Перегруз UI → максимум **5 корневых вкладок** хаба.  
- Контент базы игроков → генерация + ручной polish топ-звёзд лиги.  
- Онлайн PvP рано → только AI до product-market fit.

## Критерии готовности к стору

- [ ] Новичок за 1 матч понимает: состав → тактика → результат.  
- [ ] Live-решение заметно меняет ход таймлайна (A/B на ботах).  
- [ ] F2P проходит первые 7 дней без paywall силы.  
- [ ] VIP/pass/RV проходят модерацию формулировок Яндекса.
