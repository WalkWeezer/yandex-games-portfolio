## One-liner

Доживи рабочий день 09:00→18:00 на офисной сетке, уворачиваясь от начальства со всех сторон — иначе **ЗАСТАВИЛИ РАБОТАТЬ**.

## Fantasy / сеттинг

Открытый офис, кубиклы, столы, кулер. Боссы — карикатурные HR, директор, «СРОЧНО» и т.д. Тон — сатира и мемность. Win = **ПОВЫШЕНИЕ** на этаж.

## Core loop (~60 сек день)

1. Hub → этаж → спавн на сетке 7×9.  
2. Ходи ↑↓←→ по полу; столы блокируют.  
3. Боссы заходят с краёв; кофе = slow-mo мира; бейдж с пола = 1-hit shield.  
4. 18:00 → ПОВЫШЕНИЕ / удар → ЗАСТАВИЛИ → RV или рестарт.  
5. Мета: этажи, daily на хабе, shop, скины.

## Механики MVP (locked)

- Grid dodge, не free-move chase / hide.  
- 12 kinds с разлоком по этажам.  
- Фазы: Утро → Работа → Аврал → Переработка.  
- Рост карты каждые 25 этажей.

Полные числа: `games/deadline-escape/docs/DESIGN.md`.  
Feel: dashboard → Демка.

## Мета-прогрессия

- Daily «побег из планёрки» (с хаба).  
- Скины / shop.  
- Soft: монеты.
