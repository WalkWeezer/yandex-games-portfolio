# Replay UI — где какие слова

Страница: [`management/demos/pitch-tactics-replay.html`](../../../management/demos/pitch-tactics-replay.html)

Партии в демо (отредактированы под Freeze v1): **H**, **I**, **J**.

## Зоны экрана

| ID / место | Что пишет | Зачем |
|------------|-----------|--------|
| **Шапка / вкладки** | `H · Блок → прессинг` и т.д. | Выбор партии |
| **meta** | Подзаголовок + итоговый счёт | Контекст без спойлера стиля соперника в матче |
| **clock** | `07'` | 1 ход тренера = 1' |
| **scoreboard** | `1 : 0` | Счёт |
| **side-pill** | `Ход A` / `Ход B` / `Kick-off` / `Финал` | Чей ход |
| **banner** | `GOAL A`, `Kick-off`, `Итог 1:1` | Крупный статус шага (`uiLabels.id = banner`) |
| **paradigm** | Жёлтая капсула «Парадигма: …» | Смена плана по ходу матча |
| **Бейдж Z1/Z2/Z3** на фишке | Сон / концентрация | Персональный дебафф, не командный |
| **Бейдж D2** | Defend, осталось ходов | Стойка с таймером N=2 |
| **Бейдж ⚡** | Замах | Полностью видимый заряд |
| **Кольца на клетках** | Аура давления / подсветка Defend | Честная геометрия |
| **Панель «Бросок»** | `Удар 64% → 22 ГОЛ` | Preview % + dice result |
| **Метки на экране** | Список `uiLabels` шага | Явно: где текст должен жить в бою |
| **note** | Жёлтая врезка | Дизайн-комментарий к шагу (для ревью, не обязательно в проде) |
| **Глоссарий слева** | Ключ → «где на экране» → смысл | Обучение без скрытых правил |

## Правки партий относительно черновиков в чате

1. **Сон только на фишке** — в H на 2'–6' двигают З/ОП1, Сон Нап/ОП2 остаётся; фейл приёма у сонного ОП2.
2. **Defend сгорает по N=2** — явная метка на 4' в H.
3. **Замах всегда виден** — покер с Defend в H/I/J; лобовой % низкий; в I гол через обход.
4. **Нет скрытых дебаффов** — каждый модификатор в броске подписан (Сон2, аура, Defend).
5. **Смена парадигмы** размечена баннером, не «скриптом урока».
6. **CD замаха 5'** — второй замах только после паузы (I, J).
