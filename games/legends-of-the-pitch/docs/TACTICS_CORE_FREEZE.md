# Tactics Core Freeze v1 — пошаговый футбол (XCOM-manager)

> Зафиксировано после дизайн-прогонов (слепые PvP, концентрация, замах).  
> Это **кор матча** для исследования / replay-демо. Не путать с CCG×autochess feel lock в `DESIGN.md` Pass-2.  
> Replay UI: [`management/demos/pitch-tactics-replay.html`](../../../management/demos/pitch-tactics-replay.html)  
> Где какие подписи: [`TACTICS_REPLAY_UI.md`](./TACTICS_REPLAY_UI.md)

## Одной фразой

Пошаговый футбол 5v5: тренер тратит **2 AP** за минуту, игроки ходят по лимиту уровня, поле — **гексы**, всё видимо (как стойки в XCOM), победа только голом.

---

## Поле и состав

| Параметр | Значение |
|----------|----------|
| Сетка | **Гексогональная** flat-top, offset **12×20** (col×row), ворота у рядов 0 и 19 |
| Соседство / дистанция | кубическая дистанция на гексах (давление и длина хода) |
| Формат | **5v5**: ВР · З · ОП1 · ОП2 · Нап (зеркало) |
| Старт отряда | 5v5; позже рост как в XCOM (прокачка) |
| Клетка | 1 гекс ≈5 м смысла; макс. перемещение за действие **6** гексов |

### Скорость / ускорение

| Стат | Смысл |
|------|--------|
| **A (ускорение)** | Бюджет клеток на **первый** рывок (после приёма / старт закрытия) |
| **S (скорость)** | Бюджет на **продолжение** бега |

Профили вроде `S5/A1` (плохой контроль) и `S2/A6` (взрывной короткий) валидны. Потолок любого хода — **6**.

---

## Ход тренера и AP

- У тренера на старте карьеры: **2 AP** за ход (прокачка даст навыки, не «бесплатный 3-й AP за атаку»).
- **1 ход тренера = 1 минута** таймера (45 + перерыв + 45 в полном матче).
- Короткие PvP/тесты: срез **20'**.
- Каждое действие = **1 AP**: ход / пас / удар / отбор / Defend / Замах.
- Можно: два действия на двух игроках **или** два на одном, если позволяет уровень игрока.
- Лимит на игрока за ход тренера: **L1 → макс. 1 действие**, **L2 → макс. 2** (напр. ход+удар).

Отложенные навыки (прокачка): **Замах** и др. сильные действия — с **cooldown**, не скрытые баффы.

---

## Базовые действия (без дерева скиллов)

Все умеют: **ход, пас низом, удар, отбор, Defend**.  
Финты, ролл, сложные пассивы — только через тренировки позже.

### Defend (активная оборона)

- 1 AP, **видно** на клетке (как Hunker в XCOM).
- Длится **N чужих ходов тренера** (в демо **N = 2**), затем сгорает.
- Усиливает встречу входа с мячом в зону; не двигает всю линию одной кнопкой.

### Замах (отложенный удар)

- 1 AP, **полностью видно**.
- В этом ходу острого эффекта нет; на **следующем** ходу тренера при пасе в ударную зону — удар с отдельным % (часто без траты 2-го действия на L2 — см. replay).
- Сгорает: выбили / не пас / ушёл из зоны / истекло окно.
- **Cooldown 5'** после использования (все сильные скиллы — с CD).

## Давление

Видимая аура вокруг фишки (клетки):

| Роль | Радиус давления |
|------|-----------------|
| Защитник (З) | **2** |
| Опорный (ОП) | **1** |
| Нападающий | **0** |
| ВР | 0 (вне сейва) |

В зоне давления падают % паса / удара / удержания. Позже скиллы расширят радиус. Скрытых модификаторов нет — игрок видит ауру и preview %.

---

## Пассив формы

- До матча один пресет по умолчанию: **держать форму построения**.
- Якоря — **не магнит к мячу**. Форма держит **ширину и глубину**: крайний не схлопывается в центр, только потому что мяч ушёл на другой фланг.
- После хода тренера неактивные подправляются на **0–2 гекса к своему якорю схемы** (смещение блока относительно трети/мяча), но **сохраняют канал** (левый/центр/правый).
- Свободная зона = гекс вне аур и вне скученности. Удачный вход в удар чаще через **пустоту**, чем через скопление у мяча.
- Если все стянулись к мячу — это ошибка игрока/пресета, не «умная физика».
- Сложные пресеты (офсайд-ловушка, узкий блок) — позже.
- **Нет** действия «сдвинуть всю линию» за 1 AP.

---

## Концентрация (Сон) — по игроку

- Копит **конкретная фишка**, которая **3' подряд** без мяча и **без своего действия**.
- Уровни 0–3: каждый уровень заметно режет **её** % (приём, пас, удар, отбор).
- Сброс **только у этой** фишки, когда она снова действует.
- Пошевелили одного — остальные с Соном остаются вялыми → надо крутить **весь** состав.
- Нападающий тоже теряет концентрацию, если стоит столбом без касаний/движений.
- Исключения через прокачку/трансфер позже: «снайпер» с длинной концентрацией / иммунитетом — **явный** параметр карточки, не скрытый бафф.
- UI: иконка Сон1/2/3 на фишке + лог «Игрок X: концентрация −».

**Философия:** низкий блок не наказывается; наказывается **бездействие конкретных игроков**. Оба могут играть от обороны — это нормальный футбол; смену плана никто не форсит.

---

## Честность UI (обязательно)

Показывать всегда:

- Defend / Замах / Сон на фишках  
- Ауры давления  
- **Preview %** перед пасом/ударом/отбором (как dice/XCOM chance)  
- Результат броска после действия  

Никаких пассивных баффов/дебаффов «откуда ни возьмись».

---

## Победа и PvP

- Победа только голом; без голов — ничья (законна).
- Не наказывать поперечный пас, блок, «незрелищность».
- Стимул атаковать: очки/рейтинг и необходимость гола, не дебафф за стиль.
- Online: полная видимость стоек; ranked-срез 20' + полный 90' для лиги.

---

## Прокачка (за горизонтом демо-replay)

- Рост отряда 5→7→…  
- AP тренера / навыки переноса действия на следующий ход (заряды)  
- CD на сильные скиллы  
- Параметр концентрации / снайпер  
- Либеро-ВР как рискованный режим
