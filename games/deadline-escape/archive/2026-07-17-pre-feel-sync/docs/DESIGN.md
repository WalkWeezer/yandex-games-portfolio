## 1. Vision

**One-liner:** Убеги от начальства по офисному лабиринту, пока тебя не поймали и не заставили работать сверхурочно.

**Fantasy:** Открытый офис, кубиклы, кофемашины, принтеры, переговорки. Боссы — карикатурные менеджеры с папками «СРОЧНО». Тон — сатира, мемность, лёгкий хаос. Идеально для шаринга скринов и коротких клипов.

**Эмоциональный хук:** «Ещё 10 секунд — и рекорд» + узнаваемый офисный кошмар. Понятно за 10 секунд без текста.

**Роль в портфеле:** самый быстрый путь к деньгам и отработке SDK/модерации. Ads-first двигатель Wave 1.

---

## 2. Design Pillars

1. **Readable comedy** — юмор в силуэтах и пропах, не в стенах текста.
2. **Chase clarity** — всегда видно, откуда опасность (индикаторы боссов).
3. **Short sessions** — 30–90 сек ран; рестарт мгновенный.
4. **Gadgets over stats** — удержание через смешные предметы, не через сложный skill ceiling.
5. **Ads without grief** — interstitial на death/run end; RV revive честный.

## 4. Core Loop

```
Хаб → выбор этажа → ран 30–90с
  бегай / прячься / собирай отгулы / пауэр-апы
  ↓
Поймали → RV revive ИЛИ рестарт → interstitial
  ↓
Рекорд времени/счёта → soft → мета-апгрейды / скины
```

### Scoring

- +очки за секунду жизни  
- +бонус за «отгулы» (collectibles)  
- +бонус за успешные distraction  
- множители этажа  

Лидерборд: лучший score этажа / глобальный.

---

## 5. Gameplay Systems (overview)

### 5.1 Player

- Top-down движение (стик / WASD).
- Без стрельбы: только бег, укрытия, гаджеты.
- Стамina optional: спринт 2с с CD (мета-апгрейд).

### 5.2 Boss AI

| Boss | Поведение |
|------|-----------|
| `boss_manager` | прямое преследование, средняя скорость |
| `boss_hr` | зона «совещания» (cone slow) + chase |
| `boss_ceo` | быстрее, периодический «call all-hands» (pull) |

Состояния: roam → detect → chase → catch. Catch = game over.

### 5.3 Hide & Distract

- Кубиклы: LOS break для боссов (таймер подозрительности).
- Distraction items: уронить кулер, вызвать лифт, включить принтер — босс идёт к noise point на N сек.

### 5.4 Power-ups

| ID | Эффект | Длительность |
|----|--------|--------------|
| `pu_coffee` | +40% speed | 3с |
| `pu_badge` | invis (боссы не detect) | 2с |
| `pu_vpn` | телепорт в safe toilet zone | instant |
| `pu_donut` | босс на 2с stun (редко) | — |

### 5.5 Floors (biomes)

1. Open Space  
2. Open Space+ (больше боссов)  
3. Бухгалтерия  
4. IT-ад  
5. Совет директоров  

MVP: этаж 1 полный + 2 урезанных.

## 6. Meta Progression

- Soft currency «отгулы» / «кофейны».  
- Перманенты: moveSpeed, sprintCD, distraction radius, start power-up chance.  
- Скины героя и боссов.  
- Unlock этажей.  
- Daily «побег из планёрки».

---

## 7. Economy & Monetization (ads-first)

| Источник | Триггер |
|----------|---------|
| Interstitial | после смерти / каждые N ранов (не mid-chase) |
| Rewarded | revive (1/run), ×2 монет, временный гаджет |
| Sticky | опционально в хабе |
| IAP | Remove Ads, Starter Pack, косметика |

Currencies: soft `pto` (paid time off points), hard `coffee_beans` (IAP).

**Fair:** апгрейды ускоряют комфорт, не делают неуязвимым.

## 12. Pass-2 — согласованность (обязательно до CONFIRM)

> Добавлено после сверки с `chas-pik`. Картинки и системы по отдельности ≠ готовый продукт.

### 12.1 Одна правда MVP (Vector lock) — РЕШЕНИЕ 2026-07-17 (уточнено)

| Решение | Значение |
|---------|----------|
| Core verb | **Офисный top-down dodge на сетке** (дух chas-pik): 4 стороны, стены/столы блокируют |
| Win condition MVP | **Дожить 09:00→18:00** → повышение на этаж |
| Fail | Столкновение с боссом → «ЗАСТАВИЛИ РАБОТАТЬ» + RV revive / рестарт |
| Пространство | Сетка **7×9**: проходы + непроходимые столы/стены (не «только 3 колонны-runner») |
| Боссы | Спавн и движение **со всех сторон**; паттерны: линия / патруль / поджимание |
| Fairness | Не создавать гарантированный тупик без выхода |
| Фазы | morning → work → rush → overtime (скорость/спавн) |
| Gadget MVP | Кофе (ускорение хода) + монеты; остальные гаджеты — позже |
| Orientation | **Portrait-primary** 720×1280 |
| Отложено | Free-move chase / hide / LOS / pathfinding-stealth — не MVP |
| Feel ground truth | `management/demos` → вкладка **Демка** на странице Работник месяца |

### 12.2 Управление (Feel) — клеточный dodge

| Ввод | Поведение |
|------|-----------|
| Mobile | стик/свайп → шаг на соседнюю **ходимую** клетку (↑↓←→); в стену/стол — нельзя |
| Desktop | WASD/стрелки = один шаг за нажатие |
| Move time | ~90ms slide между клетками (ease-out, не телепорт) |
| Gadget | Кофе у коллеги → slow-mo; **щит** у коллеги → 1 удар (синий) |
| Tutorial | ран 1: «ходи по светлым проходам, избегай боссов, доживи до вечера» |

**Feel targets:** день ~30с; этаж 1–2 только HR; директор с 3; +5% скорость/этаж; лимит мобов 3 (+1/5 этажей); layout меняется каждый этаж.

### 12.3 Удержание внутри сессии

```
09:00 Утро — редкие боссы, в основном прямые заходы
→ Работа — базовый ритм, патрули
→ Аврал — чаще спавн с разных краёв, иногда 2 угрозы
→ Переработка — максимум давления + поджимание
18:00 = ПОВЫШЕНИЕ → этаж+1 (новый день / layout)
Столкновение → ЗАСТАВИЛИ → рестарт / RV
```

### 12.4 Почему вернуться завтра (Retention)

| Крючок | Частота | Награда |
|--------|---------|---------|
| Daily «побег из планёрки» | 1/день | гарантированный гаджет + soft |
| Рекорд этажа | всегда | лидерборд / шаринг |
| Unlock этажа N | прогресс | новый биом + босс |
| Скин за N ранов | 3–5 ранов | косметика |
| Streak 3 дня | daily | ×1.5 soft на день |

Без daily + рекорда D1 из §11 неисполним.

### 12.5 Как наращивается контент

Контент = **новый encounter recipe / layout trait**, не только tint:

| Этаж | Signature | Encounter |
|------|-----------|-----------|
| Open Space | длинные аллеи кубиклов | 1 manager chase |
| Accounting | узкие ряды шкафов | HR cone + manager |
| IT-ад | серверные LOS-ломалки | быстрый intern + printer noise |

Пайплайн: concept floor → layout ASCII → feel demo на фигурах → арт.
