Слот портфеля #04. Заменяет «Легенды Поля» (отменены: механика CCG×autochess не формулируется).

1. Vision

Игрок — менеджер футбольного клуба. Между матчами он ведёт клуб как в классическом онлайн-менеджере (календарь, состав, трансферы, база). В матче думает как в Football Manager: формация, роли, инструкции — и может 2–3 раза вмешаться live. Никаких карт, гачи и autochess.

Эмоциональный тон: вечерний спортивный хаб — зелень поля, тёмно-синий UI клуба, белый текст таблицы, акцент на гербе и счёте. Без неона и «карточных рамок».

2. Design Pillars

  1. Один жанр — только футбольный менеджер; всё, что не клуб/матч/таблица, режется.
  2. Компоновка, не изобретение — SoccerLife-оболочка + FM-lite ядро + live-control.
  3. Матч читается — игрок понимает почему проиграл (отчёт + xG-лайт + ключевые события).
  4. Сила = решения, не paywall статов.
  5. 5 вкладок хаба максимум — Hub / Squad / Tactics / Match / Club.

3. Target Audience & Session

Параметр Значение
Возраст 16–45, в основном м
Сессия короткая 3–7 мин (хаб, тренировка, рынок)
Сессия матч-дня 8–15 мин
Первый «вау» ≤90 сек: расставил состав → свисток → гол/момент
Удержание D1 ≥35%, D7 ≥15% (midcore-спорт)

4. Core Loop

Хаб → (Состав / Тактика) → Матч (симуляция + live) → Отчёт
        ↑_________________________________________|
                         ↓
              Тренировка / Трансфер / База / Таблица
  1. Открыл клуб → увидел следующий матч и место в таблице.
  2. Выставил 11 и 3 инструкции.
  3. Сыграл/досмотрел матч с live-вмешательствами.
  4. Получил очки, деньги, сдвиг формы.
  5. Потратил 2–5 минут на развитие клуба до следующего тура.

5. Systems Overview

5.1 Клуб и сезон (оболочка SoccerLife)

Система MVP Позже
Лига 16 клубов, круговой мини-сезон несколько дивизионов
Календарь 2–3 матча/нед, кубок later полный кубок + евро
Финансы баланс, зарплата-паушально, приз за матч спонсоры-тиры
Инфраструктура База / Стадион / Академия (ур. 1–5) ещё 2 здания
Ячейки клубов 1 бесплатно, +1 VIP как SoccerLife

5.2 Игрок и атрибуты (сжатый FM)

ID Имя На что влияет
PAC Темп контратаки, 1v1 в штрафной
SHT Удар реализация моментов
PAS Пас удержание, создание шансов
DEF Оборона отборы, меньше xG соперника
PHY Физика усталость, воздух
MEN Менталка форма, давление счёта

Позиции: GK, CB, FB, DM, CM, AM, W, ST.
Роли MVP (навешиваются на слот): Защитник, Плеймейкер, Бокс-ту-бокс, Инсайд, Чистый нападающий, Вратарь-свипер (6 ролей).

5.3 Тактика FM-lite

Формации: 4-3-3, 4-4-2, 3-5-2.
Инструкции (4):

Инструкция Low Med High
Прессинг низкий блок стандарт высокий пресс
Ширина узко норма широко
Темп медленно норма быстро
Риск держать счёт баланс все вперёд

5.4 Матч-движок (событийный)

Не физика 11v11. Тики ≈ минуты матча. На тике считаются: контроль, создание шанса, удар, сейв — от сумм атрибутов линий + модификаторов инструкций + формы + home bonus.

Live-control (лимит 3 за матч):

  1. Сменить одну инструкцию.
  2. Замена (1 игрок).
  3. Эмо-кнопка: «Автобус» или «Все вперёд» на 10–15 мин.

5.5 Post-match

Счёт, xG обеих команд, лучший игрок, 3 ключевых события, совет «что не сработало» (1 строка). Это и есть «ощущение FM» без Excel.

3.4 Match event

type MatchEvent =
  | { t: number; type: "chance"; side: "home"|"away"; xg: number; scorerId?: string; outcome: "goal"|"save"|"miss"|"block" }
  | { t: number; type: "card"|"injury"|"sub"; side: "home"|"away"; playerId: string }
  | { t: number; type: "live"; side: "home"|"away"; action: "instr"|"sub"|"emotion" };

4. Match engine contract

4.1 Tick

  • Match length: 90 ticks (1 tick ≈ 1 min). UI может ускорять x2/x4.
  • Каждый тик: обновить fatigue; с шансом pChance создать момент.

4.2 Chance probability (целевая чувственность)

attackPower = line(FWD attrs) * tempoMult * riskMult * formMult
defensePower = line(DEF attrs) * pressMult_opponent * homeMult
pChance ≈ clamp(0.02 .. 0.18, attack/(attack+defense) * base)
xg ≈ f(SHT, DEF_opp, chanceType)
pGoal ≈ xg

Инструкции дают мультипликаторы 0.85–1.20, не ломают матч одним тапом.

4.3 Live actions

Action Effect Cost
Change instruction set one InstrLevel 1 live charge
Substitution swap lineup↔bench 1 live charge
Emotion bus/all-out risk=0 or 2 for 12 ticks 1 live charge

Default charges: 3. VIP: 4.

4.4 Report must answer

  1. Счёт + xG.
  2. Лучший игрок.
  3. Три события.
  4. Одна строка совета (press too low, no width, stamina collapse…).

5. Meta systems

5.1 Training (1 plan / day)

Plans: Attack / Defense / Fitness.
Effect: +form to 3 players OR −fatigue squad (числа в data/training.json).

5.2 Transfers lite

  • Рынок: 8–12 листингов, реролл 1/day free, RV extra.
  • Buy if cash >= value. Tokens: sniper bid skip wait (convenience).

5.3 Buildings

Building Effect per level
Training +training yield
Stadium +match income
Academy +youth soft player раз в N дней

Max level 5 in MVP.

5.4 Season

  • 16 clubs, double round-robin truncated OR 14 matchdays — выбрать одно в data: default 14 matchdays (каждый играет каждого почти раз).
  • Points 3/1/0. Table on Hub.
  • Season reset → keep buildings −1 floor soft, keep VIP cosmetics.
