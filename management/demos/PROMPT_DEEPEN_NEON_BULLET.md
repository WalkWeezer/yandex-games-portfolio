## МЕТОД УГЛУБЛЕНИЯ (порядок слоёв)

Работай **строго по слоям**. Не прыгай к мета/wireframe, пока слой 1–3 не ощущается.

### Слой 0 — Инвентаризация (1 проход)

- Прочитай текущую демку и DESIGN (Pass-2 / feel targets).
- Коротко выпиши: что уже есть, что врёт дизайну, что ломает feel.
- Если демка снова ушла в waves — сначала верни combat-puzzle, потом контент.

### Слой 1 — Читаемый core loop

Цель: за 5–10 секунд понятно «что делать / как проиграть / как выиграть».

- Движение: twin-stick / стик+кнопка огня; aim отделён от facing при возможности.
- Стены честно режут движение и **ломают vision**.
- FAIL и WIN считываются с HUD (DEATH / CLEAR→EXIT / EXIT OK).
- Рестарт мгновенный; длина рана ~45–75с при умелой игре, быстрее при ошибках.

### Слой 2 — Угрозы как роли (паттерны), не как скины

Каждый тип = читаемый паттерн (ориентир Neontron):

| Тип | Паттерн (демка-минимум) |
|-----|-------------------------|
| patrol | конус вперёд, медленный поворот/патруль |
| shotgun | короткая дистанция, широкий конус / рывок внимания |
| shield | фланг: спереди танк, уязвим сзади/сбоку |
| sniper (later) | узкий длинный конус, редкий |

Правила:

- Разлок: сначала 1 patrol → +shotgun → +shield; sniper не раньше стабильного слоя 3.
- Лимит одновременности на маленькой карте: ориентир 2–4 живых; не спавнить бесконечно.
- Vision не проходит сквозь стены.
- Движение врагов **плавное** (без телепортов по клеткам).

### Слой 3 — Кривая сложности (внутри рана + между ранами)

1. **Внутри миссии:** alarm / давление после обнаружения умеренное (не мгновенный aimbot на всю карту). Потолок «паники» ≤ +25% к стартовой агрессии.
2. **Между миссиями/этажами демки:** медленный рост (+1 враг или +1 тип редко), не +5% скорости каждый рестарт.
3. **Лэйаут:** 2–3 пресета комнат; менять расстановку укрытий, не только tint.
4. Опционально: silent-bonus (не засветиться) как множитель очков — не блокер win.

### Слой 4 — Бонусы / гаджеты (fantasy, не статы)

- 1–2 штуки с полом: **оружие pickup** (бита/дробовик = другие правила выстрела) и/или **маска-импульс** (короткий dash / тишина 2с).
- Предмет **падает на пол → подобрать** (не меню апгрейдов mid-run).
- Индикация на игроке + HUD обязательна.

### Слой 5 — Dev-инструменты playtest

Минимум:

- God-mode / бессмертие.
- Счётчик «смертей» в god-mode: сколько раз и на каком пресете «убило бы».
- Dev-выбор стартового пресета комнаты / набора врагов.
- Нормальный режим стартует с пресета 1; после смерти — рестарт пресета (не сброс всего сейва меты).

### Слой 6 — Wireframe UI (отдельная вкладка)

- Вкладка **Wireframe UI** на `management/projects/neon-bullet.html` (через `tools/build_dashboard.py` при необходимости).
- Portrait 360×640, dashed-блоки.
- Экраны минимум: Boot, Menu/Hub (city или pager-lite), Mission select, Briefing, Run HUD, Pause, Death/Retry, Results (rank C–S), Shop (маски), Daily (если в дизайне).
- Сначала иерархия/CTA, не пиксель-арт.

### Слой 7 — Мета-решения (DESIGN + wireframe)

Зафиксируй явно:

1. Прогресс миссий: unlock + выбор в хабе (демка может стартовать с tut_01).
2. Daily: вход с хаба, не модалка перед каждым ретраем.
3. Смерть = конец рана, не сброс всех анлоков.
4. Age: 12+ dissolve (канон); blood не возвращать.
5. RV continue mid-mission: **решение open** — либо 1× как в старом DESIGN, либо retry-only как Neontron; зафиксируй одно.

Обнови feel targets / Pass-2 в `DESIGN.md` коротко.
