5) МАТЧ (критично — feel)
═══════════════════════════════════════

Действия в зоне (соседи / своя клетка): пас, навес, отбор, перехват, удар, сейв (+ контроль).

Обязательно:
1. **Мяч летит** (lerp/smoothstep + лёгкая дуга). Запрещён телепорт giveBall без полёта на пас/удар.
2. После важного момента — **beat/pause** (0.4–1.5с), чтобы успеть прочитать: пас / отбор / сейв / гол.
3. Нет вечного пас-пинг-понга A↔B: запрет мгновенного возврата, давление вперёд, иначе удар/вынос.
4. Мини-анимации: lunge на пас/отбор/удар, «ручки», idle-дыхание.
5. Тактики ×2/×3 реально меняют частоты моментов (прессинг / короткие пасы / блок / контра / бровки).
6. Кнопка ×2 скорости. HUD: счёт · минута · тактики.
